# Cotizador Sunname

Cotizador de implementaciones Odoo de Sunname: paquete de horas, proyecto y análisis GAP.

- PDF de la cotización con folio y logo
- Historial de cotizaciones, seguimiento y exportación a Excel
- Autorización de descuentos y configuración de tarifas

Todo el cotizador vive en `index.html`. En esta versión (GitHub Pages) las cotizaciones y la configuración se guardan en el navegador de cada persona.

Colores de marca: variables `--marca-*` al inicio de `index.html`. Logo: constantes `LOGO_CLARO` y `LOGO_OSCURO`.
